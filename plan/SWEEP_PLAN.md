## Base and design

- **Base = G1** (`configs/grid_oss_sim_k2.yaml`):
  - simultaneous turns, N=10, 20 rounds, 5 keys and 3 needs per agent, 2 copies per info;
  - God K=2: message_fraud in r3, then cot_control (scratchpad replace) in r5;
  - openai/gpt-oss-120b, reasoning_effort low, provider_sort price, `salvage_truncated` on.
- **One factor changes per cell.** Each cell is a paired God/no-God fork on the same worlds:
  run.seed 1 and game_idx 0..n-1, which are G1's first n worlds.
- **Configs:** `configs/sweep_*.yaml`, generated by `infra/sweep/make_configs.py`.
- **Cost-saving design for the God-only cells** (start round, K):
  - Each cell sets `runner.fork.control_god` to G1's god section. This is a new runner option,
    default off, tested in `tests/runner/test_spec.py`.
  - The cell's control branch therefore has exactly G1's nogod game_id, config hash and seeds.
    The God branch shares that game_id too (common random numbers).
  - The control replays from the LLM cache for free, and the God branch replays G1's cached
    prefix up to its own first intervention. Only rounds from that point on are paid.
  - **Caveat (measured in the smoke):** responses with empty text, from a `finish=length` cut,
    are never cached. A replay therefore re-samples from the first such call onward:
    - 3 of G1's 16 nogod games have one, at r6, r8 and r6;
    - from that round on, the control is a fresh God-free continuation, not G1's game.
  - Every Δ is computed against the cell's **own** control branch. That control equals G1's
    nogod game exactly unless the break happened.
- **Game cells** (keys, N, rounds) change the world itself, so they get their own paired control.
  Rounds 1-2 are shared via the cache, as in G1.

- **Stage 1** (factors 1, 2 and 4): projected $1.77 (new seeds), hard caps $2.105, so the total stays ≤ $2.30.


- `infra/sweep/launch.sh` reads the key file inside the command and never echoes it.
- The `k=v` cell options only reshape the driver's projected-cost model. The fields are:
  - `n`: agents;
  - `g` and `pcap`: prompt growth per round and its cap. These were fitted from the smokes:
    N=20 grows about 820 tokens per round up to 16k; N=5 grows about 230;
  - `shared`: rounds the forks share;
  - `free=1`: the control is replayed from the cache;
  - `seeds`: the number of paid seeds. Seed 0 of k1, n5 and n20 is a cached smoke game, so
    counting it would inflate the projection.

## Abort conditions (watchdog = `infra/grid_driver.py`, every 10 s, log `runs/sweep_driver.log`)

The abort conditions are the same as the main grid's:
- MemAvailable < 15 GB;
- more than 20 rg processes;
- ledger ≥ **$7.80**;
- live projected cell cost > the cell's hard cap (after 150 paid calls);
- LLM errors > 5% or any HTTP 400;
- parse failures > 10% of turns;
- finish=length > 5% of responses;
- per branch: > 10% call errors, or > 30% error-noop turns.

An abort kills that cell's process group and starts no further cells in that driver.

Two more safeguards:
- **Run budget cap:** a cell that hits `llm.budget_usd` ends its games with
  `budget_exceeded`. Those seeds are dropped as unhealthy by `grid_stats.load_run`, and so by
  `sweep_stats`.
- **Analysis-side health check:** the same health rule applied to every branch, so a seed with an
  unhealthy branch is dropped and reported.

## Analysis

`swarm/analysis/sweep_stats.py` reports these per cell, as paired God − noGod per seed:
- welfare, win rate, burned and lost needs per agent, and rounds;
- defects (and wrong defects), gives, board posts and DMs per agent;
- divergence (ripple, coarse action signatures): the share of agents ever diverged, and the mean
  post-fork share of agents diverged per round.

Each comes as a mean with a 95% bootstrap CI (10k), an exact sign-flip p and n. G1 and G3 are
restricted to the same seeds 0-7.

Figures: `infra/sweep/plot.py` draws Δwelfare and Δdivergence against the factor value, one pair
per factor, into `plan/figs/`.
